# 🎮 DevQuest

DevQuest é um sistema de quiz interativo desenvolvido com Node.js, Express e JavaScript puro no frontend.  
O objetivo é simular uma plataforma de perguntas e respostas com sistema de usuários, login, cadastro e pontuação (XP).

---

## 🚀 Funcionalidades

- 👤 Cadastro de usuários
- 🔐 Login de usuários
- 🎯 Sistema de perguntas e respostas (quiz)
- ⭐ Sistema de XP (pontuação)
- 📊 Contador de acertos e erros
- 🔄 Perguntas aleatórias a cada partida
- 🎮 Interface simples e interativa

---

## 🧠 Proposta do Projeto

O DevQuest foi criado para simular um sistema de aprendizado gamificado, onde o usuário responde perguntas e acumula pontos (XP) conforme seu desempenho.

---

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express
- JavaScript (Vanilla)
- HTML5
- CSS3
- API REST
